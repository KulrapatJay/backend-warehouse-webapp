    - ลง npx prisma init    
    - สร้าง model ใน schema.prisma ให้สำเร็จ
    - หลังสร้าง model เสร็จให้ทำการ npx prisma generate ต่อ
    - ตามด้วย npx prisma migrate dev --name <--ชื่อที่จะ migrate--> เพื่อลงข้อมูลเข้าไปใน database
